# dev CI 실행 중단, main CI 유지

- 날짜: 2026-11-05
- 영역: 공통
- 관련: #214

## 목적

- dev 머지 큐가 PR마다 CI(lint·test 약 5분)를 기다리던 대기 제거

## 한 일

- `.github/workflows/ci.yml`: 트리거를 main 대상 `pull_request`로 한정, dev `push` 트리거 제거
- `CLAUDE.md`, `AGENTS.md`: DB 테스트 안내를 바뀐 CI 범위에 맞춤

## 결정과 근거

- dev 머지 검증은 머지 큐가 로컬에서 `REQUIRE_DB_TESTS=1 make test`, `make lint`로 대신함
- main 대상 PR의 CI와 `deploy.yml`(main push)은 그대로 둠
- `collaboration-policy.yml`(PR·Issue 양식 검사, 약 20초)은 CI가 아니라 그대로 둠

## 검증

- 워크플로 트리거만 바꾼 변경. 이 PR(dev 대상)에서 `CI / lint·test`가 돌지 않는 것으로 확인

## 남은 일·확인 필요

- dev → main 배포 PR에서는 CI가 그대로 돌아야 함
