# 결재용 PDF API

- 날짜: 2026-11-05
- 영역: server
- 관련: #150, F-APPROVAL-04, REV-07

## 목적

- 승인된 검토의 결재용 PDF를 스냅샷 기반으로 생성

## 한 일

- `reviews/pdf.py`: HTML 템플릿, 재고 추이 matplotlib SVG, WeasyPrint 렌더링
- `api/review_pdf.py`: `GET /reviews/{id}/pdf`, 승인 전 409 `PDF_NOT_READY`
- `apps/server/Dockerfile`: `libpango-1.0-0`, `libpangoft2-1.0-0`, `fonts-noto-cjk`
- 의존성 `weasyprint`, `matplotlib`, 테스트 `test_review_pdf.py` 5개, 문서 REV-07

## 결정과 근거

- 기능명세서 F-APPROVAL-04대로 WeasyPrint·matplotlib(사용자 결정)
- 같은 바이트를 위해 생성 시각을 넣지 않고 SVG 해시 솔트·메타데이터를 고정
- 재고 추이는 m 기준 단순 추정(명세에 계산 방식 없음)
- 승인 API(#162) 전이라 테스트는 승인 상태를 직접 저장

## 검증

- 로컬 PostgreSQL 16 `REQUIRE_DB_TESTS=1 make test` 745개 통과·1개 모듈 건너뜀(macOS `make`가 `DYLD_*`를 지워 PDF 테스트 생략), `make lint` 통과
- `DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib uv run pytest` PDF 테스트 5개 통과, 한글 렌더링 확인
- 서버 Docker 이미지 빌드 후 WeasyPrint PDF 생성·한글 글꼴 확인
