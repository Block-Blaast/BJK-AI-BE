## 결정과 근거

- 발주 이력은 초기 재고 이관(이력 시작) 전에 입고된 기록으로 둠. 원장 입고와 연결하지 않아 현재 재고·출고 이력은 그대로
- 시작 재고를 쪼개 이력 안의 입고로 넣는 방식은 MOQ가 큰 부품(6205ZZ MOQ 10)에 표본이 생기지 않아 채택 안 함
- V벨트 A-42는 API 명세서 REV-02 예시(최근 단가 평균 13,000원, σ 1,200, 4건)에 맞춘 기본 공급사 단가 이력만 둠
- 납기 = 공급사 기본 납기 + (-1, 0, 0, 1, 2, 3) 중 고정 난수, 수량은 MOQ와 포장 단위 중 큰 값
