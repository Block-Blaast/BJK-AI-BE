# 3D 창고 배치·예측 API 추가

- 날짜: 2026-11-05
- 영역: server
- 관련: #281, W-11, F-ANAL-07·08, F-MATCH-03, F-AUDIT

## 목적

- 프론트 3D 창고 목업 `/api/twin/layout`, `/api/twin/projection`을 서버 API로 대체

## 한 일

- `twin_layouts` 테이블(마이그레이션 0031, RLS, 회사당 한 줄 JSONB)과 시연 시드 더미 배치(선반 5, 설비 3, 부품 6)
- `GET /api/v1/twin/layout`(manager 이상): 저장 배치 + 설비 이름·연결 부품은 설비 테이블 기준, 병합 부품은 대표 부품으로
- `GET /api/v1/twin/projection`(manager 이상): 부품별 8주 날짜별 재고·상태·결품 확률, 설비 상태·손실, 입고 예정. `with_orders=true`면 결정 대기 수정안 포함
- `domain/twin.py`: 중앙값 경로·결품 확률·설비 상태 순수 함수
- 테스트 `test_twin.py` 8개

## 결정과 근거

- 사용자 결정: 명세 밖 화면이지만 서버가 목업을 대체하고 배치는 실제 DB 더미 데이터로 둠
- 형식은 프론트 `types/twin.ts`를 그대로 따름. 계산식도 프론트 목업(`simulate.ts`)과 같게 해 목업과 서버의 색 규칙이 같음
- 배치는 정규화 테이블 대신 JSONB 한 줄. 편집 화면이 없어 구조가 확정되지 않았기 때문
- 결품 확률은 정규 근사라 부품 지표·검토의 경로 시뮬레이션 `p_out`과 다를 수 있음(문서에 명시)
- 도착 예상일이 지난 열린 발주는 오늘 도착으로 봄(목업은 제외)

## 남은 일·확인 필요

- 배치 편집 API(선반·칸 지정)와 부품 `location` 문자열과의 연결
- 프론트 경로를 `/v1/twin/...`으로 바꾸기
